# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this
repository. Do not open a public issue containing credentials, tenant data,
account identifiers, exploit details, or screenshots from a real environment.

Include the affected script or function, the potential impact, reproduction
steps using fictional data, and any suggested mitigation. Reports will be
acknowledged through GitHub and coordinated before public disclosure.

## Supported versions

Security fixes are made on the default branch. Tagged releases are supported
until a newer release is published.
